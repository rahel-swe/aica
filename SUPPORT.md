# Support

Use GitHub issues for reproducible bugs and scoped feature requests.

Before opening an issue:

- Search existing issues.
- Confirm the problem still happens on the latest default branch.
- Include clear reproduction steps.
- Include relevant package context: `client`, `server`, or `contracts`.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

For broad product ideas, start with a discussion when discussions are available. Keep issues focused enough that a contributor can act on them.
