# Licensing

This repository uses the `Apache-2.0` license.

## Why this fits AICA

- It is a real open-source license.
- It is simple enough for contributors and companies to adopt.
- It includes an express patent grant, which is stronger than MIT for a
  production-oriented software project.
- It keeps the project open without forcing every downstream product to use the
  same license.

## What is covered

Unless a file or directory says otherwise, this license covers:

- source code
- prompts
- documentation
- structured pathway-domain seed data

## What is not automatically granted

`Apache-2.0` does not grant trademark rights.

That means people can reuse the repository contents, but they should not assume
they can present their fork or derivative as the official AICA project or reuse
its branding without permission.

## If AICA later needs stronger restrictions

If the project later needs stronger protection against closed hosted-service
forks, the usual path would be `AGPL-3.0`.

For now, `Apache-2.0` is the better fit for broad open-source adoption.
